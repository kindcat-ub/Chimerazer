# Валидация записи `0F:02` (эффект LED) — Razer Naga Pro

Процедура: `docs/ARCHITECTURE.md`, «Первичная аппаратная валидация записи». Экземпляр: `1532:008F` (провод) и `1532:0090` (свисток), прошивка 2.03. Коммит `0be3b9b`. Логи — у владельца, `~/chimerazer-m2/light/`.

**Статус в каталоге не меняется этим протоколом:** статический цвет (`09`) — `ExternalHardware`, Spectrum (`06`) — `SourceOnly`; повышение до `OurHardware` — решением владельца. В обычный режим (`VERIFIED_WRITES`, `restore`) `0F:02` не добавлен.

## Формат (подтверждён чтением обратно)

- Чтение `0F:82 [storage, led]`, ответ `[storage, led, effect, …]`. Исходное состояние обоих LED (логотип `04`, колесо `01`) в профиле 1 и в живом слое: `03 00 00 00 00 00 00 00 00 00` — Spectrum.
- Статический цвет: `0F:02` размер `09`, `[storage, led, 01, 00, 00, 01, r, g, b]` → чтение `01 00 00 01 ff 00 ff 00 00 00` для `#FF00FF`.
- Spectrum: `0F:02` размер `06`, `[storage, led, 03, 00, 00, 00]` → чтение `03 00 00 00 00 00 00 00 00 00`. Запись Spectrum возвращает исходное состояние байт в байт.

| Шаг | Логотип `04` | Колесо `01` |
|---|---|---|
| Исходный дамп (провод) | 235 значений, 0 ошибок | — |
| 2–4, живой слой: Spectrum тем же значением → `#FF00FF` → Spectrum, полный снимок | **PASSED** | **PASSED** |
| Профиль 1 (`hold`, провод): Spectrum тем же значением → `#FF00FF`; яркость 51 → 255 | **PASSED** | **PASSED** |
| Отражение в живом слое | `diff`: 8 ключей — `p1`/`live` effect и яркость обоих LED | |
| Визуально (владелец), кабель подключён | статичная фуксия, без анимации | |
| Выключение питания на 10 с, чтение через свисток | `diff` с дампом после записи: `identical (235 keys)` | |
| Визуально после включения | статичная фуксия, без анимации | |

Первая попытка `hold` была отклонена шлюзом до отправки кадров (не передан `--allow-source-only` для записи Spectrum тем же значением); `diff` с исходным дампом — identical.

## Вывод

- Статический цвет и яркость, записанные в профиль 1, хранятся в постоянной памяти мыши и работают после полного выключения, без Synapse и без Chimerazer.
- Форма Spectrum `0F:02/06` на Naga Pro работает: подтверждена записью того же значения и возвратом в живом слое, записью того же значения в профиль 1.
- Не проверено: возврат Spectrum в профиль 1 после смены эффекта (владелец оставил фуксию; возврат — `chimerazer finish hold-light-2.txt --baseline base.txt`), запись эффекта через свисток, профили 2–5, другие эффекты.
- Конечное состояние мыши: профиль 1, логотип и колесо — статический `#FF00FF`, яркость 255.
