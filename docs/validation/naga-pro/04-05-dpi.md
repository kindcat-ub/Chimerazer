# Валидация записи `04:05` (DPI) — Razer Naga Pro

Процедура: `docs/ARCHITECTURE.md`, «Первичная аппаратная валидация записи». **Статус:** `OurHardware` (решение владельца, 2026-10-29). Шаг 5 (неназначенный банк 5) исключён из обязательной процедуры: запись, чтение, возврат и сохранение после переподключения подтверждены на профиле 1.

**Подтверждённая область применения** (только здесь `04:05` допускается в обычном режиме, `VERIFIED_WRITES`): провод: `storage 0`, `storage 1`; свисток: `storage 0`, `storage 1`. Профили 2–5 — только через новую первичную валидацию.

## Вывод

- Живой слой (`storage 0`) — оперативная память: запись действует до переподключения, затем мышь загружает значение из активного профиля.
- Профиль (`storage 1`, активный) — постоянная память: запись переживает отключение USB. Запись в активный профиль сразу отражается в живом слое (`04:85 00` показал пробу без отдельной записи в `storage 0`).

## Прогон 1: живой слой через свисток

- Экземпляр: Razer Naga Pro, `1532:0090` (свисток), прошивка 2.03. Серийный номер не записывается.
- Инструмент: `chimerazer validate dpi --storage 0 --probe 800 --baseline baseline.txt --pid 0090` (коммит `fdff09f`).
- Исходный дамп: 235 значений, 0 ошибок; совпал с устройством перед записью.
- Результат: **PASSED**. Все три записи подтверждены статусом `02` и эхом аргументов; контрольный дамп после прогона идентичен исходному (235 ключей).

## Прогон 2: живой слой по проводу

- `1532:008F`, прошивка 2.03, коммит `fd4eaf1`; исходный дамп 235 значений, 0 ошибок.

## Прогон 3: сохранение после переподключения (провод)

- `validate … --hold`: записаны 1600 (то же значение) и 800 (проба), обе подтверждены чтением; проба оставлена. Отдельное чтение `04:85 00` показало 800×800.
- Кабель выдернут на 5 секунд и подключён обратно.
- `finish`: **PASSED**. `after reconnect: 1600x1600 — the device reverted to the original value`; затем записано 1600, прочитано 1600; итоговый снимок совпал с исходным дампом.
- Контрольный дамп после всего: `identical (235 keys compared)`.

## Прогон 4: профиль 1 по проводу

- `1532:008F`, прошивка 2.03, коммит `5504591`; исходный дамп 235 значений, 0 ошибок.
- `validate dpi --storage 1 --probe 800`: **PASSED**. Записи `04:05` с `storage 01`: 1600, 800, 1600; каждая подтверждена статусом `02` и чтением `04:85 01`. Итоговый снимок совпал с исходным дампом.

## Прогон 5: сохранение профиля 1 после переподключения

- `validate … --storage 1 --hold`: проба 800 оставлена в профиле 1.
- Сразу после записи: `04:85 00` → 800×800, `04:85 01` → 800×800 (профиль отражается в живой слой).
- Кабель выдернут на 5 секунд и подключён обратно.
- После переподключения: `04:85 00` → 800×800, `04:85 01` → 800×800.
- `finish`: **PASSED** — `after reconnect: 800x800 — the probe survived the reconnect`; затем записано 1600, прочитано 1600; итоговый снимок совпал с исходным дампом.
- Контрольный дамп: `identical (235 keys compared)`.
- Не проверено: полное отключение питания беспроводной мыши, сохранение через свисток.

## Прогон 6: профиль 1 через свисток и полное выключение питания (2026-10-29, `1532:0090`, коммит `834c564`)

Пакетно с остальными командами M2: `hold dpi:1:800 dpi-stages:1:active=2 brightness:1:logo:100 brightness:1:scroll_wheel:100 --pid 0090`, кабель отключён.

- Исходный дамп через свисток: 235 значений, 0 ошибок; профиль 1: DPI 1600×1600, `active=3`, яркость обоих LED 51.
- `hold`: запись того же значения и пробы, с чтением после каждой записи — `PASSED: 4 value(s)`.
- Мышь выключена переключателем на 10 с и включена (свисток переподключился сам).
- `finish`: сначала чтение всех четырёх значений, до любой записи — `after reconnect: 800x800 — the probe survived the reconnect`; затем возврат исходных. Итог: `PASSED: 4 value(s), persistence PASSED`.
- Дамп после `finish` против исходного: `identical (235 keys compared)`.
